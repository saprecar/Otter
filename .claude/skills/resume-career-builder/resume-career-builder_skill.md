# Resume & Career Builder Skill

## Purpose
Builds elite resumes, technical job applications, and career profiles engineered to pass Applicant Tracking Systems (ATS) and impress hiring managers. Strips robotic AI writing habits.

## 1. Google XYZ Achievement Formula
Every bullet point MUST follow:
$$\text{"Accomplished [X] as measured by [Y] by doing [Z]"}$$

- **Bad (AI Slop)**: *"Responsible for improving application speed and working with cross-functional teams."*
- **Elite (XYZ Standard)**: *"Reduced API response latency by 42% (from 850ms to 490ms) across 2M daily requests by implementing Redis caching and query indexing."*

## 2. Anti-Slop Writing Rules
- **Banned Buzzwords**: *"Dynamic team player"*, *"Results-driven professional"*, *"Proven track record"*, *"Passionate visionary"*, *"Spearheaded initiatives"*.
- **Direct Action Verbs**: Use precise technical verbs: *Architected, Deployed, Benchmarked, Automated, Engineered, Refactored, Shipped*.
- **Metrics First**: Every technical role entry must have at least 2 quantifiable numbers (%, latency, dollars saved, users served).

## 3. Resume Output Standards
- **ATS Single-Column Format**: Single-column clean markdown or standard LaTeX. Avoid multi-column tables that break ATS parsers.
- **Section Order**:
  1. Header (Name, Location, GitHub, LinkedIn, Contact)
  2. Technical Skills Matrix (Languages, Frameworks, Cloud, Databases)
  3. Work Experience (Reverse chronological, 3-4 bullets each)
  4. Selected Projects / Open Source (Highlight GitHub links and live demos)
  5. Education & Certifications
